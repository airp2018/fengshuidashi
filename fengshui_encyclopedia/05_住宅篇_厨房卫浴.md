## 一、厨房风水

厨房是"食禄"之源，代表家庭的财运和健康。炉灶属火，是厨房的核心。

### 厨房的理想方位

| 方位 | 宜忌 | 原理 |
|------|------|------|
| **正东（震）** | ✅大吉 | 东属木，木生火，三吉方 |
| **东南（巽）** | ✅大吉 | 东南属木，木生火，最宜厨房 |
| **正南（离）** | ⚠️一般 | 南属火，火火过旺，易脾气暴躁 |
| **正西（兑）** | ❌不宜 | 西属金，火克金，不利财运 |
| **西北（乾）** | ❌不宜 | 乾属金，火克金，伤男主人 |
| **正北（坎）** | ❌不宜 | 北属水，水火相冲 |
| **西南（坤）** | ❌不宜 | 西南属土，火生土，泄火气 |
| **东北（艮）** | ⚠️一般 | 东北属土，火生土 |

### 厨房宜忌速查

**宜：**
- 厨房宜设在东、东南方（木生火）
- 厨房宜位于住宅的后半部
- 厨房宜通风良好（有抽油烟机和排风扇）
- 灶台宜摆在生气方
- 炉口宜朝向屋主生气方
- 炉灶宜安放在南方（火得位）
- 水槽与灶位宜顺排（水火协调）
- 厨房地面宜用防滑砖
- 厨房墙面宜用易清洁材料
- 厨房宜保持干燥整洁

**忌：**
- 厨房忌设在南、西南方（火过旺）
- 厨房忌设在住宅中央（火气中心）
- 厨房忌设在西北（火烧天门，伤男主人）
- 厨房忌正对大门（财气直冲）
- 厨房忌正对卧室门（火气影响睡眠）
- 厨房忌正对厕所门（水火相冲）
- 厨房忌正对灶台（门冲火）
- 灶台忌安放在西方（金被火克）
- 燃气炉忌摆在凶方
- 水槽与冰箱忌紧挨（水火不容）
- 炉灶忌上方有横梁
- 厨房忌阴暗潮湿
- 炉灶忌背后无靠（背后最好是墙）
- 炉灶忌正对冰箱（冷热相冲）
- 炉灶忌正对水槽（水火相冲）

### 厨房布局三要

**炉灶（火）：**
- 宜放在厨房吉方（生气、延年、天医）
- 宜背后有靠（靠实墙）
- 宜左右有空间（操作方便）
- 忌正对门
- 忌正对窗户（风对炉火）

**水槽（水）：**
- 宜靠近窗户（采光通风）
- 宜与炉灶保持距离（不相冲）
- 忌与冰箱相邻（冷热相冲）

**冰箱（水）：**
- 宜放在厨房角落（稳定）
- 忌正对炉灶（火水冲）
- 忌放在门口（进出不便）
- 冰箱上不宜放重物

### 厨房颜色选择

| 方位 | 推荐颜色 | 说明 |
|------|----------|------|
| 东/东南（木） | 白色、米色、浅绿 | 木生火，用白色（金）适度克木 |
| 南（火） | 白色、银色、浅黄 | 火过旺，用白色降温 |
| 其他方位 | 白色、米色、浅灰 | 厨房通用色，干净清爽 |

## 二、卫浴风水

卫浴是住宅中"水"最集中的地方，代表排泄和净化，处理不当会影响健康和财运。

### 卫浴的理想方位

| 方位 | 宜忌 | 说明 |
|------|------|------|
| **住宅四角** | ✅宜 | 凶方压煞（厕所宜在凶方） |
| **正东（震）** | ❌不宜 | 东为生气方，不宜做厕所 |
| **东南（巽）** | ❌不宜 | 财位方，不宜做厕所 |
| **正南（离）** | ❌不宜 | 火方，水冲火不利 |
| **正北（坎）** | ❌不宜 | 北方水位，水水重叠 |
| **住宅中心** | ❌大忌 | 污秽中心，最凶 |

### 卫浴宜忌速查

**宜：**
- 卫浴宜设在住宅四周的凶方（压制凶气）
- 卫生间宜有窗户通风
- 卫生间宜干湿分离
- 马桶宜与户门垂直错开
- 卫浴地面宜低于外部（防止水气外流）
- 卫浴宜用防水、防滑材料
- 卫浴宜保持干燥洁净

**忌：**
- 卫浴忌设在房子中央（最凶）
- 卫浴忌设在北方（水水重叠）
- 卫浴忌正对大门（秽气直冲）
- 卫浴忌正对卧室门（影响健康）
- 卫浴忌正对厨房门（水火相冲）
- 卫浴忌正对餐厅（影响食欲）
- 卫浴忌在楼梯下方
- 马桶忌在正四线和四隅线上（不吉）
- 卫浴忌改造成卧室（楼上可能是别人厕所）
- 卫浴忌紧邻厨房
- 卫浴门忌长期敞开

### 卫生间改造

| 不利情况 | 化解方法 |
|----------|----------|
| 卫浴在房屋中心 | 无法彻底化解，建议重新规划 |
| 卫浴在北方 | 保持干燥通风，用暖色调 |
| 卫浴在东南/东方 | 保持干净，常关厕所门，放土性饰物 |
| 卫浴对大门 | 中间设屏风、挂珠帘 |
| 卫浴对卧室 | 常关厕所门，挂门帘 |

## 三、阳台风水

阳台是住宅与外界的过渡空间，相当于住宅的"明堂"。

### 阳台的理想朝向

| 朝向 | 吉凶 | 说明 |
|------|------|------|
| **正东** | ✅大吉 | 紫气东来，迎旺气 |
| **正南** | ✅大吉 | 阳光充足，冬暖夏凉 |
| **正西** | ❌不宜 | 西晒严重，热气入室 |
| **正北** | ❌不宜 | 冬季北风，寒冷不利 |
| **东南** | ✅大吉 | 最佳朝向，采光好通风佳 |
| **西南** | ⚠️一般 | 午后西晒 |
| **西北** | ❌不宜 | 西北风寒冷 |
| **东北** | ⚠️一般 | 早晨冷风 |

### 阳台宜忌

**宜：**
- 阳台宜面向正东、正南、东南
- 阳台宜保持整洁通畅
- 阳台宜种植绿化植物（旺生气）
- 阳台宜与大门错开（不直冲）
- 阳台宜装隐形防盗网（不影响视野）

**忌：**
- 阳台忌面向正北、正西
- 阳台忌直冲街道（噪音和煞气）
- 阳台忌正对厨房（油烟倒灌）
- 阳台忌堆放过多杂物
- 阳台忌与大门形成直线（穿堂煞）
- 阳台忌放重物超过承重
- 阳台忌封闭过死（影响通风）

### 阳台植物选择

| 方位 | 推荐植物 | 说明 |
|------|----------|------|
| 东/东南 | 发财树、绿萝、富贵竹 | 木气旺，生发 |
| 南 | 石榴、月季、米兰 | 喜阳植物 |
| 西/西北 | 仙人掌、龙骨、量天尺 | 化西晒煞气 |
| 北 | 文竹、龟背竹、万年青 | 喜阴植物 |

## 四、庭院风水

### 庭院方位宜忌

| 方位 | 宜忌 | 说明 |
|------|------|------|
| **南方** | ✅宜 | 阳光充足，适合庭院 |
| **东方** | ✅宜 | 紫气东来，生机盎然 |
| **北方** | ❌忌 | 阳光不足，阴冷潮湿 |
| **西方** | ⚠️一般 | 西晒强烈 |

### 庭院水体（池塘）

**宜：**
- 池塘宜置于西、西北方（金生水）
- 池塘宜在庭院右侧（白虎位）
- 水宜活水（流动水为佳）
- 水宜清澈

**忌：**
- 池塘忌置于住宅正前方（明堂属水不吉）
- 池塘忌置于住宅正后方（无靠）
- 池塘忌置于东北、西南方（土克水）
- 池塘忌死水（发臭）
- 池塘忌过于靠近房屋基础

### 庭院假山

**宜：**
- 假山宜置于西北方（乾为山）
- 假山宜在庭院左侧（青龙位）
- 假山石形宜圆润柔和

**忌：**
- 假山忌置于东、东南方（木被土克）
- 假山忌过于尖锐（尖角煞）
- 假山忌正对门窗
- 假山忌造型怪异

### 庭院植物

**宜种：**
| 植物 | 寓意 |
|------|------|
| 竹子 | 节节高升，平安吉祥 |
| 桂花 | 富贵吉祥，贵人相助 |
| 石榴 | 多子多福 |
| 松树 | 长寿，坚韧 |
| 梅树 | 五福临门 |
| 橘树 | 大吉大利 |
| 棕榈 | 生财护宅 |

**忌种：**
- 桑树（谐音"丧"）
- 柳树（谐音"流"，流财）
- 杨树（叶响如鬼拍手）
- 槐树（木中有鬼）
- 芭蕉（招阴）
- 藤蔓过多（阴气重）
