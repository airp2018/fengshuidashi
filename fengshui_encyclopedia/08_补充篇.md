## 一、情感与爱情风水

> 来源：S10《500个风水常识》情感篇

### 催旺桃花位

| 生肖 | 桃花位 |
|------|--------|
| 猪、兔、羊 | 正北方 |
| 蛇、鸡、牛 | 正南方 |
| 虎、马、狗 | 正东方 |
| 猴、鼠、龙 | 正西方 |

**催旺方法：** 在桃花位用淡紫色花器，插粉红玫瑰或桃花一枝，或银柳。保持鲜花不枯萎。

### 卧室爱情风水宜忌

**宜：**
- 卧室光线宜柔和舒适
- 夫妻房间宜摆放合照及成双成对的物品（一对台灯、一对爱心饰物）
- 床头放一杯水（陶瓷杯或磁杯，不可以用热水）——有助于睡眠和魅力
- 卧室宜用暖色系（红、橙、黄）饰品增强感情活力
- 单身者摆放鲜花：男生在客厅右手边，女生在客厅左手边（以坐在沙发方向为准），用瓷瓶或陶瓶，放大花瓣鲜花

**忌：**
- 卧室忌摆电饭锅、微波炉等电器（火气高亢，不利夫妻关系）
- 卧室忌摆黑色家具（黑色象征浊水，污染爱情运）
- 卧室床头忌摆鲜花（易招桃花，一方会有外遇）
- 卧室内忌有过多的金属窗架（会让心硬冷，爱情褪色）
- 卧室下忌有水沟（运气全流掉）
- 卧室忌摆空花瓶或破花瓶（象征爱情残缺）
- 卧室忌摆前男友/前女友的礼物（易起猜忌）
- 床位忌太接近大窗户（易"红杏出墙"）
- 床上方忌有直灯（竖灯如把身体切开）
- 床上方不宜有横梁压顶

### 其他爱情风水

| 问题 | 解决方法 |
|------|----------|
| 感情冷淡 | 在家里的花瓶上方装一盏聚光灯，集中精神接受美感信息 |
| 想增加桃花 | 在床头放花瓶，插桃花3株，睡前说出自己及喜欢的人名字，持续7天 |
| 总吵架 | 检查家里是否摆面具或露牙齿的玩具——容易增加吵架机率 |
| 单身无桃花 | 客厅摆放鲜花，男右女左，用大花瓣鲜花，陶瓷瓶，保持鲜活 |
| 办公室恋情问题 | 办公桌不宜用玻璃桌面（不扎根）、不宜圆形或不规则形（易生畸恋） |

## 二、学业与文昌风水详解

> 来源：S10《500个风水常识》学业篇

### 文昌用品与布置

| 物品 | 作用 | 摆放方式 |
|------|------|----------|
| 文昌塔（九层） | 利读书、功名、事业 | 摆放在文昌位或书桌上，天然水晶最佳 |
| 文昌笔（毛笔） | 代表文昌，四支代表四绿 | 放笔架上，摆书桌 |
| 四支富贵竹 | 旺文昌（四绿） | 放在东南桃花位 |
| 一杯清水 | 催旺流年文昌 | 放在文昌位，适时更换 |
| 绿色植物 | 木气旺文昌 | 放在书房正南或文昌位 |

### 学业风水宜忌

**宜：**
- 孩子房间以绿色为主调（文昌属木）
- 书房空调宜放在北方（增强文昌运）
- 书房宜朝东方或南方开窗（采光纳气）
- 书柜宜摆放在凶位（书桌坐吉、书柜坐凶）
- 书房宜用木质书橱（木主春，增阳气）
- 书桌宜面向正南（增旺文化学习气场）
- 考试前可在正北位放四支竹、文昌塔或吊一支毛笔
- 核桃多吃（五行属木，以形补形，补脑）
- 早起空腹一杯温开水（平衡文昌位水火）

**忌：**
- 书房不宜过大（聚气难）
- 书房灯光不宜过强或过彩（扰乱视线）
- 书桌不宜放在房间中央（四方孤立）
- 孩子卧室不宜摆设电脑、电视
- 孩子卧室墙壁不宜过花哨（心乱烦躁）
- 孩子卧室天花板忌悬吊怪饰物（半夜惊吓）
- 孩子卧室忌挂太多风铃（精神衰弱）
- 孩子房间不宜放古董物品（衰败之气）
- 书桌前方不宜有高物压迫（头痛）
- 书桌不可正对屋外屋脊、电杆、壁刀角（头痛或开刀）

### 不利于学业的十种风水

1. 卧室天花板悬吊怪饰物——半夜惊吓
2. 卧室悬挂太多风铃——易使精神衰弱
3. 墙壁贴奇形怪状的动物画像——易做怪梦
4. 床位在阳台水池假山下——读书不专心
5. 床位在神厅、神位正下方——易做噩梦
6. 书桌右方有马达转动——书读不下去
7. 床头有冷气机、抽风机——头晕耳痛
8. 床头靠厕所马桶前后——在家待不住
9. 书桌前有高物压迫——头痛
10. 书桌正对屋外屋脊或电杆——头痛或开刀

## 三、楼梯风水

> 来源：S09《顺风顺水》第八章

### 楼梯的理想设置

**宜：**
- 楼梯宜靠墙而立
- 楼梯宜用木质材料（接气缓和，自然）
- 楼梯坡度宜缓和
- 以螺旋梯或半途有转弯平台的楼梯为首选
- 楼梯底下宜摆放植物或做储物柜

**忌：**
- 楼梯忌正对大门（气冲门而出——可在对面放凸镜化解）
- 楼梯忌用石材或金属（产生尖锐气场）
- 楼梯忌坡度太陡（负面效果强）
- 楼梯尽头平台忌在房屋中心（大凶）
- 楼梯底下忌作餐厅、厨房、卧室
- 楼梯忌在宅中央（兄弟姐妹不和）

### 走廊过道风水

**宜：**
- 走廊宜保持明亮（不可太阴暗）
- 走廊吊顶宜做假天花（如有横梁必须做）
- 走廊范围要得当，不宜太长
- 走廊宽度建议：
  - 通往卧室、客厅：≥1.2米
  - 通往厨房、卫浴、储物间：≥0.9米
  - 庭院过道：≥1.9米
- 走廊灯坏了要及时修理

**忌：**
- 走廊忌太狭长（影响夫妻感情）
- 走廊天花柜忌摆放利器
- 走廊忌太阴暗（不利于家人运气）
- 走廊灯光忌五颜六色（如五把箭，情绪不安稳）
- 忌过道把完整住宅一分为二（"断情分手房"）

## 五、庭院植树禁忌详解

> 来源：S09《顺风顺水》第九章

**庭院宜植树种：**
- 椿树——代表长寿
- 槐树——代表"禄"
- 桃树——避邪
- 柏树——驱邪
- 樟、松、楠——昌盛不衰
- 橘树——大吉大利
- 竹子——节节高升

**庭院忌：**
- 庭院中央不宜植树（挡光、破坏平坦）
- 宅前不宜有树倾斜（安全隐患）
- 前门不宜有枯树（地气有问题）
- 窗前不宜有树太近（至少距离2米以上，否则招阴湿）
- 大树不宜正对大门
- 忌种桑树（谐音"丧"）
- 忌种柳树（谐音"流"）
- 忌种杨树（叶响如鬼拍手）
- 忌种槐树（木中有鬼）
- 藤蔓不宜过多覆盖（阴气重）

## 六、更多煞气与化解

### 住宅外部环境煞气

| 煞名 | 现象 | 影响 | 化解 |
|------|------|------|------|
| 蜈蚣煞 | 屋外有排水管、煤气管如蜈蚣形 | 健康受损 | 挂公鸡或凸镜 |
| 凹风煞 | 住宅受风口吹袭 | 健康、运势受损 | 设置屏风 |
| 烟囱煞 | 正对烟囱或排气口 | 意外、口舌 | 挂山海镇 |
| 反光煞 | 玻璃幕墙、水面反光入室 | 精神紧张、烦躁 | 挂厚窗帘、贴磨砂膜 |
| 声煞 | 噪音干扰（马路、施工） | 失眠、神经衰弱 | 装隔音窗、厚窗帘 |
| 天桥煞 | 天桥环抱或直冲住宅 | 破财、意外 | 挂八卦凸镜 |
| 割脚水 | 住宅紧邻水流或马路 | 破财、不聚财 | 门槛加高 |
| 哭字屋 | 门窗排列成"哭"字形 | 家人哭泣之事 | 改造门窗 |
| 双口煞 | 两个大门并列或相对 | 家庭不和 | 封一扇门 |
| 披麻屋 | 外墙装饰如披麻 | 家运衰败 | 重新装修 |
| 穿心煞 | 大门直对后门或窗户 | 财来财去 | 设玄关/屏风 |
| 枪煞 | 长路、长走廊直冲门窗 | 健康事业受损 | 挂五帝钱 |
| 尖射煞 | 尖角、屋角冲射 | 意外伤灾 | 放绿色植物 |
| 反弓煞 | 道路弯弓对住宅 | 破财、血光 | 放泰山石敢当 |
| 天斩煞 | 两楼缝隙对住宅 | 健康受损 | 挂八卦凸镜 |
| 孤峰煞 | 独楼高耸四周无靠 | 孤立无助 | 靠背位放高柜 |
| 泰山压顶 | 四周高楼唯己低矮 | 运势难伸 | 挂山海镇 |

| 目的 | 方法 |
|------|------|
| 催旺桃花 | 客厅放鲜花，男右女左；卧室用暖色系 |
