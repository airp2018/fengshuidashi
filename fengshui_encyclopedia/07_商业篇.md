## 一、商铺选址

### 商铺的地段选择

**宜：**
- 商铺宜开在繁华之地（人气旺）
- 商铺宜开在"天井"、天桥口附近（聚人气）
- 商铺宜选择十字路口（四通八达）
- 商铺宜在商业中心、购物中心
- 商铺宜在居民区出入口
- 商铺宜在车站、地铁站附近

**忌：**
- 商铺忌开在偏僻之地
- 商铺忌开在"Y"字形路口（路冲）
- 商铺忌在立交桥下（气流杂乱）
- 商铺忌在天桥正下方（压迫感）
- 商铺忌在死胡同尽头
- 商铺忌在垃圾站、厕所旁
- 商铺忌取低洼狭窄之向

### 商铺朝向

**宜：**
- 商铺宜朝向正东、正南（阳气足）
- 商铺宜朝向人流来向
- 商铺宜朝向与自然景观谐调
- 商铺宜店门宽敞（吸纳人气）

**忌：**
- 商铺忌朝向正西、西北（西晒，人气少）
- 商铺忌两门相对（竞争激烈）
- 商铺忌向着天桥（反弓煞）
- 商铺忌正对丁字路口（路冲）

### 各类型店铺选址

| 店铺类型 | 推荐位置 | 说明 |
|----------|----------|------|
| **日用品店** | 居民区内 | 靠近日常消费群体 |
| **服装店** | 商业街、购物中心 | 人流密集处 |
| **餐饮店** | 办公区、学校旁 | 午间和晚间人流 |
| **文具店** | 学校附近 | 学生消费群 |
| **美容美发** | 社区商业街 | 居民日常需求 |
| **超市** | 社区中心 | 周边居民消费 |
| **药店** | 医院附近、社区 | 刚需消费 |
| **家电** | 商业街、专业市场 | 目的性消费 |
| **珠宝首饰** | 高端商业区 | 消费能力匹配 |
| **性保健用品** | 偏静处 | 隐私需求 |
| **干洗店** | 社区内部 | 便利为主 |
| **咖啡馆** | 办公区、文创区 | 休闲消费 |

### 商铺门面

**宜：**
- 商铺宜店门宽敞明亮
- 商铺招牌宜醒目大方
- 商铺门面宜清洁整齐
- 商铺门口宜有缓冲空间
- 商铺橱窗宜明亮通透

**忌：**
- 商铺忌店门狭窄
- 商铺忌招牌太小或不清晰
- 商铺忌门前有障碍物
- 商铺忌门口有台阶过高（难进入）
- 商铺忌橱窗昏暗

## 二、商铺内部布局

### 收银台

**宜：**
- 收银台宜设在进门显眼位置
- 收银台宜在店铺财位（进门对角）
- 收银台宜背后有靠
- 收银台宜保持整洁
- 收银台宜放招财吉祥物（金蟾、貔貅）

**忌：**
- 收银台忌设在进门的"龙"边（左边为龙）
- 收银台忌正对大门（路冲）
- 收银台忌靠近厕所
- 收银台忌杂乱无章
- 收银台忌在楼梯下

### 商品陈列

**宜：**
- 畅销品宜放在显眼处
- 新品宜放在门口附近
- 高利润商品宜在黄金位置（视线高度）
- 商品陈列宜整齐有序
- 通道宜宽敞（不拥挤）

**忌：**
- 忌死角堆货（影响气流）
- 忌陈列过于密集（压抑）
- 忌通道狭窄（顾客不愿进入）
- 忌贵重物品在门口（不安全）
- 忌入口堆放过多商品（阻碍进入）

### 商铺财位

**确定：**
- 固定财位：进门对角线的位置
- 流动财位：根据当值年星推算

**财位宜：**
- 宜明亮
- 宜放招财物（金蟾、貔貅、水晶、聚宝盆）
- 宜放绿色植物（阔叶为佳）

**财位忌：**
- 忌杂乱
-忌 阴暗
-忌 有尖角冲射

## 三、各类商业空间风水

### 餐饮店

**宜：**
- 厨房宜在店后部（不显眼）
- 餐桌间距宜宽敞
- 餐厅灯光宜暖色（增加食欲）
- 收银台宜在入口对角线
- 店门口宜有菜单展示

**忌：**
- 忌厨房正对店门（油烟冲出）
- 忌厕所靠近用餐区
- 忌餐桌在横梁下
- 忌店门直冲长路

### 服装店

**宜：**
- 橱窗宜展示最新款式
- 试衣间宜在店铺深处
- 灯光宜柔和明亮
- 镜子宜多（扩大空间感）

**忌：**
- 忌试衣间在门口
-忌 试衣间对镜子（隐私）
-忌 颜色过于昏暗

### 超市/便利店

**宜：**
- 入口宜在左边（龙边入）
- 收银台宜在出口处
- 热销品宜在视线高度
- 通道宜横平竖直

**忌：**
- 忌收银台对门
-忌 通道过于狭窄
-忌 冷柜在门口（寒气外泄）

### 宾馆/酒店

（来源：S05《旺铺办公室风水宝典》）

**宜：**
- 大堂宜宽敞明亮
- 前台宜在门侧（不直冲）
- 客房走廊宜有自然光
- 客房入口宜设玄关（缓冲）
- 总统套房宜在顶层吉方

**忌：**
- 忌大堂正对大门（无缓冲）
- 忌走廊过暗（阴气重）
- 忌客房对楼梯或电梯
- 忌客房在横梁下
- 忌房间号带4

### 茶馆/咖啡厅

**宜：**
- 宜设在安静、有文化氛围处
- 座位宜有私密性
- 灯光宜柔和
- 宜有自然元素（植物、水景）

**忌：**
- 忌在嘈杂环境
- 忌灯光过亮
- 忌座位过于密集

### 娱乐场所（KTV、酒吧）

**宜：**
- 宜在商业区（不扰民）
- 入口宜宽大
- 内部宜有动线规划
- 音响宜隔音处理

**忌：**
- 忌在居民楼下
- 忌在寺庙、学校旁
- 忌灯光过于昏暗

## 四、商铺吉祥物

| 吉祥物 | 用途 | 摆放位置 |
|--------|------|----------|
| 金蟾（嘴含钱） | 招财进宝 | 收银台或财位，头朝店内 |
| 貔貅 | 招财镇宅 | 收银台或门口，头朝外 |
| 招财猫 | 招客 | 门口或收银台，左手招人右手招财 |
| 五帝钱 | 化煞招财 | 挂在收银台或门口 |
| 水晶球 | 聚财 | 收银台或财位 |
| 财神 | 招财 | 店铺显眼处 |
| 关公像 | 镇宅 | 正对门口 |
| 金元宝 | 招财 | 收银台或财位 |
