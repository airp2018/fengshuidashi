# 住宅篇 · 大门 · 玄关 · 窗户

> 综合整理自S03《住宅风水指南》、S04《现代家居与风水》、S07《方位风水宜忌》

## 一、大门风水

大门是住宅的"气口"，纳气之关键，吉气从大门入，凶气也从大门入。

### 大门的理想方位

| 方位 | 宜忌 | 说明 |
|------|------|------|
| **正东（震）** | ✅大吉 | 旭日东升，生气勃勃，有利于事业发展 |
| **正南（离）** | ✅吉 | 南风送暖，采光好，利于社交和名声 |
| **东南（巽）** | ✅吉 | 紫气东来，财运亨通 |
| **正西（兑）** | ⚠️一般 | 西风萧瑟，大门向西的住宅要在门前设屏风 |
| **正北（坎）** | ⚠️一般 | 冬天北风直入，不利保暖，需设玄关化解 |
| **西南（坤）** | ❌不宜 | 鬼门方位，不利家宅平安 |
| **东北（艮）** | ❌不宜 | 鬼门方位，阴气较重 |
| **西北（乾）** | ⚠️偏吉 | 宜男主人，但不宜正对大门 |

### 大门宜忌速查

**宜：**
- 大门宜开在正东、正南方向
- 大门前宜开阔明亮，有明堂
- 大门宜配合路形、地理环境
- 门前宜有缓冲空间（门廊、台阶）
- 大门宜比邻居大门略大（主气强）
- 门前宜整洁干净

**忌：**
- 大门忌正对后门或窗户（穿堂煞，财来财去）
- 大门忌正对楼梯（向下泄气，向上冲煞）
- 大门忌正对厕所门（秽气直冲）
- 大门忌正对厨房门（火气冲门）
- 大门忌正对镜子（反射吉气）
- 大门忌正对大树、电线杆、灯柱（顶心煞）
- 大门忌正对寺庙、医院、殡仪馆
- 大门忌在西南、东北方（鬼门方）
- 大门忌直冲长路（枪煞）
- 大门忌对墙角、屋角（尖角煞）
- 大门宅卦忌与命卦方位错位
- 前门忌正对后门（穿心煞）

### 门对门化解

| 情形 | 化解方法 |
|------|----------|
| 自家大门对邻居大门 | 在门槛内埋五帝钱，或门口挂中国结 |
| 大门对电梯门 | 门口设玄关、屏风，或挂五帝钱 |
| 大门对下行楼梯 | 门槛加高，挂八卦凸镜 |
| 大门对上行楼梯 | 在楼梯口放植物 |
| 大门对厕所 | 中间设屏风、珠帘，或长期关厕所门 |
| 大门对厨房 | 设玄关或挂珠帘隔断 |
| 大门对卧室门 | 设玄关或用屏风遮挡 |
| 大门对镜子 | 移开镜子或改用小镜 |

### 大门的颜色选择

| 方位 | 适宜颜色 | 不适宜颜色 |
|------|----------|------------|
| 正东/东南（木） | 绿色、青色、蓝色 | 白色、金色、银色 |
| 正南（火） | 红色、橙色、紫色 | 黑色、蓝色 |
| 西南/东北（土） | 黄色、米色、棕色 | 绿色、青色 |
| 正西/西北（金） | 白色、金色、银色 | 红色、橙色、紫色 |
| 正北（水） | 黑色、蓝色 | 黄色、棕色 |

## 二、玄关风水

玄关是大门到客厅的过渡空间，起缓冲、聚气、挡煞的作用。

### 玄关的方位

| 情形 | 宜忌 | 说明 |
|------|------|------|
| 设在东南方 | ✅宜 | 财位，利于聚财 |
| 设在正东 | ✅宜 | 生气方，利于事业 |
| 设在正南 | ✅宜 | 明堂方，利于名声 |
| 设在东北 | ❌忌 | 鬼门方，不利家运 |
| 设在西南 | ❌忌 | 鬼门方，易招阴气 |

### 玄关宜忌

**宜：**
- 玄关宜设在东南方
- 玄关宜明亮（用灯光补充）
- 玄关宜整洁，避免堆放杂物
- 玄关鞋柜鞋头宜朝上摆放（鞋头向上有步步高升之意）
- 玄关地面宜用防滑、易清洁材料
- 玄关宜设镜子（方便出门整理仪容，但不对门）
- 玄关可放吉祥物：如貔貅、铜钱、中国结

**忌：**
- 玄关忌设在东北方
- 玄关忌阴暗潮湿
- 鞋柜忌居中摆放
- 玄关镜子忌正对大门（反射财气）
- 玄关忌过于狭窄（不足1.2米宽）
- 玄关忌横梁压顶
- 玄关忌堆放过多鞋子

### 鞋柜风水

| 项目 | 宜 | 忌 |
|------|----|-----|
| 位置 | 玄关两侧（白虎位） | 玄关正中央 |
| 高度 | 不超过身高三分之一 | 过高（压顶） |
| 鞋子摆放 | 鞋头朝上 | 鞋头朝下 |
| 数量 | 够用即可 | 过多外露 |
| 密闭性 | 有柜门关闭 | 敞开式外露 |

## 三、窗户风水

窗户是住宅的"眼睛"，与大门共同负责采光、通风、纳气。

### 窗户的理想朝向

| 朝向 | 宜忌 | 说明 |
|------|------|------|
| **东** | ✅大吉 | 旭日东升，紫气东来，有利于健康和活力 |
| **东南** | ✅大吉 | 春风吹拂，采光通风好，有利财运 |
| **南** | ✅吉 | 阳光充足，冬暖夏凉 |
| **西** | ⚠️一般 | 西晒强烈，夏季炎热，需要遮阳措施 |
| **北** | ❌不宜 | 采光差，冬季寒风入室，不利保暖 |
| **东北** | ⚠️一般 | 冬季寒风，朝东北的开窗宜小不宜大 |
| **西南** | ⚠️一般 | 午后西晒，夏季炎热 |
| **西北** | ❌不宜 | 冬季西北风凛冽 |

### 窗户宜忌

**宜：**
- 开窗宜朝东、东南
- 窗户宜正对"九曲水"（弯曲河流或道路）
- 窗户宜保持清洁明亮
- 窗户数量宜均衡（三扇或以下，不宜过多）
- 落地窗宜配窗帘保护隐私

**忌：**
- 开窗忌朝北方（冬季寒风）
- 窗户忌过少（通风不良）
- 窗户忌过多（气散不聚）
- 窗户忌被大树、建筑物遮挡视野
- 窗户忌正对医院、烟囱、垃圾站
- 窗户忌正对邻居的墙角（尖角煞）
- 窗户忌对路冲（枪煞）

### 窗户形状五行

| 形状 | 五行 | 适用方位 |
|------|------|----------|
| 圆形/拱形 | 金 | 西、西北 |
| 长方形 | 木 | 东、东南 |
| 三角形/尖形 | 火 | 南 |
| 方形 | 土 | 东北、西南 |
| 波浪形 | 水 | 北 |

## 四、整宅大格局

### 住宅形状吉凶

| 形状 | 吉凶 | 说明 |
|------|------|------|
| 正方形 | ✅大吉 | 四平八稳，阴阳平衡 |
| 长方形 | ✅吉 | 前后略长，藏风聚气 |
| 前窄后宽 | ✅吉 | 聚财格局（如口袋） |
| 前宽后窄 | ❌凶 | 散财格局（如漏斗） |
| L形（缺角） | ⚠️欠佳 | 缺哪个角就影响对应家庭成员 |
| 三角形 | ❌凶 | 火形，容易引发口舌是非 |
| 梯形 | ⚠️看朝向 | 前窄后宽吉，前宽后窄凶 |

### 房屋缺角影响

| 缺角方位 | 对应家庭成员 | 影响 |
|----------|-------------|------|
| 正东（震） | 长子、长男 | 事业受阻，肝胆疾病 |
| 东南（巽） | 长女 | 财运不佳，人际关系差 |
| 正南（离） | 中女 | 名声受损，眼疾 |
| 西南（坤） | 母亲、女主人 | 妇科疾病，家庭不和 |
| 正西（兑） | 少女 | 口舌是非，肺部疾病 |
| 西北（乾） | 父亲、男主人 | 事业受阻，头部疾病（最严重） |
| 正北（坎） | 中男 | 肾虚、耳疾，智慧受阻 |
| 东北（艮） | 少男 | 脾胃不好，手脚不利 |

### 宅内房间布局总则

- 客厅宜在住宅前方（靠近大门）
- 卧室宜在住宅后方（安静区域）
- 厨房宜在住宅东、东南方（木火相生）
- 卫浴宜在住宅四角（凶方压制）
- 楼梯宜在住宅左侧（青龙位）
- 厕所不宜在房屋中心
- 厨房不宜在房屋中心
