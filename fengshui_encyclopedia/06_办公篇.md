## 一、办公室选址

### 写字楼外部环境

| 条件 | 宜忌 | 说明 |
|------|------|------|
| 来路纳气 | ✅宜 | 前方道路弯曲有情，车流和缓 |
| 前低后高 | ✅宜 | 背后有靠（有高楼或山），前方开阔 |
| 坐实向虚 | ✅宜 | 背后有建筑靠山，前方空旷 |
| 朱雀争鸣 | ✅宜 | 前方有活动（广场、公园），人气汇聚 |
| 虎强龙弱 | ❌忌 | 右边建筑高于左边 |
| 道路太直 | ❌忌 | 直冲煞气，不利聚财 |
| 车流杂乱 | ❌忌 | 噪音和气流混乱 |
| 峤煞 | ❌忌 | 周围有高大建筑压迫 |
| 背后无靠 | ❌忌 | 办公楼后面空旷无遮拦 |

### 道路与方位

**宜：**
- 办公室前宜来路纳气（弯曲道路）
- 办公楼周围宜有环抱道路（玉带环腰）
- 办公楼宜选择十字路口附近（交通便利）
- 办公地势宜前低后高

**忌：**
- 办公室前忌道路太直（直冲煞）
- 办公楼前忌车流杂乱
- 办公楼的周遭忌有峤煞（高大建筑冲射）
- 办公楼忌在立交桥旁（气流混乱）
- 办公楼忌在道路反弓处（反弓煞）

### 办公大门

**宜：**
- 办公大门宜开在大楼左边（龙边）
- 办公大门宜避开岔路和死巷
- 办公大门宜比周围公司略大

**忌：**
- 办公前门忌正对后门（穿堂煞）
- 办公室忌开很多偏门（气散）
- 办公大门忌对着大树、庙宇、寺观
- 办公大门忌正对走廊和通道（枪煞）

## 二、内部格局

### 前台

**宜：**
- 办公前台宜直面大门
- 前台宜宽敞明亮
- 前台背景墙宜稳重大气
- 前台宜设在旺位

**忌：**
- 办公前台忌镜子直照门外（反射吉气）
- 前台忌正对厕所
- 前台忌阴暗

### 会议室

**宜：**
- 会议室宜设在办公室前部
- 会议室宜有足够采光
- 会议室门宜常关（聚气）
- 会议桌宜长方形或椭圆形

**忌：**
- 会议室忌位于阴暗方
- 会议室忌在厕所旁边
- 会议桌忌有尖角

### 员工办公区

**宜：**
- 办公桌宜整齐排列（方向一致）
- 办公桌宜背后有靠（靠墙或隔断）
- 办公桌宜左方靠窗（左青龙高）
- 办公坐位宜前方开阔（明堂宽）
- 通道宜宽敞通畅
- 办公区宜光线充足

**忌：**
- 办公桌忌正对大门（开门冲）
- 办公桌忌正对厕所门（秽气）
- 办公坐位忌被电器包围（电磁辐射）
- 办公桌忌背对门（不能看来人）
- 办公区忌阴暗（影响士气）
- 办公桌忌在横梁下
- 办公桌忌正对柱子（柱冲）
- 员工坐位忌背对背（形成对抗）

### 办公桌朝向

| 朝向 | 宜忌 | 说明 |
|------|------|------|
| 面朝大门方向 | ✅宜 | 能看到来人，掌握全局 |
| 面向东南 | ✅宜 | 紫气东来，利于事业 |
| 背靠实墙 | ✅宜 | 背后有靠，安心工作 |
| 面对墙壁 | ❌忌 | 视野受限 |
| 背对门 | ❌忌 | 背后无防，易受干扰 |

### 电脑摆放

**宜：**
- 电脑宜放在办公桌左侧（青龙位）
- 电脑屏幕宜与视线平齐

**忌：**
- 电脑忌直射门口
- 电脑忌正对坐位（对同事形成冲射）
- 电脑忌放在右手边（白虎位动）

## 三、经理室/总经理室

经理室是整个办公室的核心，风水影响企业决策和发展。

### 经理室位置

**宜：**
- 经理室宜在卦位吉方（生气、延年、天医）
- 总经理室宜设在旺气生财位
- 总经理办公方位宜靠后（后方坐镇）
- 经理室宜在整层楼的财位
- 经理室门前宜开阔

**忌：**
- 总经理室忌位于无气方
- 总经理室忌位于凶方（绝命、五鬼）
- 总经理室忌缺西北角（乾位缺，不利决策）
- 总经理室忌四面敞开（无隐私）

### 经理办公桌

**宜：**
- 经理办公桌宜向门（能看到门口）
- 总经理桌前宜明堂开阔
- 经理桌宜比员工的大
- 经理椅宜高背（有靠山）

**忌：**
- 经理办公桌忌背门（背后无防）
- 经理室门忌正对大门（主管被门冲）
- 经理桌忌放在门边
- 经理桌忌在横梁下
- 经理桌忌靠在厕所墙

### 财务室

**宜：**
- 财务室宜设在财位方（进门对角）
- 财务室宜在安静角落
- 财务柜宜放在财务主管身后

**忌：**
- 财务室忌直冲大门（财气外泄）
- 财务室忌在人来人往处
- 财务室忌过于开放
- 财务室忌在厕所旁边

## 五、家庭办公风水

### 家庭办公区设置

**宜：**
- 家庭办公区宜有独立空间
- 办公桌宜在书房或客厅一角
- 办公区宜与休息区分开
- 家庭办公宜设在东南文昌位

**忌：**
- 忌在卧室办公（影响休息）
- 忌在餐厅办公（影响用餐）
- 忌背对门办公
- 忌办公区与娱乐区混在一起

### 家庭办公桌摆放

**宜：**
- 宜面朝门口或窗户（视野开阔）
- 宜背后有靠墙
- 宜在文昌位
- 电脑宜在左方（青龙位）

**忌：**
- 忌在横梁下
- 忌正对镜子
- 忌背后是窗户
- 忌在楼梯下
