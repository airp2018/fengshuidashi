## 一、客厅风水

客厅是住宅的核心，是全家人活动的中心，也是接待客人的主要场所，其风水影响全家人的运势。

### 客厅的理想方位

| 方位 | 宜忌 | 说明 |
|------|------|------|
| **住宅中央** | ✅大吉 | 客厅在中央，全家活动中心，利于聚气 |
| **正南（离）** | ✅吉 | 阳光充足，利于名声和社会活动 |
| **正东（震）** | ✅吉 | 紫气东来，生机勃勃 |
| **东南（巽）** | ✅吉 | 财位方向，利于财运 |
| **正西（兑）** | ⚠️一般 | 可设客厅但需注意西晒 |
| **正北（坎）** | ⚠️一般 | 阳气不足，需用灯光补足 |
| **西南（坤）** | ❌不宜 | 鬼门方，不宜做主要活动区 |
| **东北（艮）** | ❌不宜 | 鬼门方 |
| **住宅后半部** | ❌不宜 | 客厅应在住宅前半部 |

### 客厅宜忌速查

**宜：**
- 客厅宜设在住宅中央或前半部
- 客厅宜宽敞明亮，采光充足
- 沙发宜背后有靠（靠实墙）
- 沙发宜呈U形或L形排列（聚气）
- 客厅财位（进门对角线位置）宜平整、明亮、有靠
- 电视背景墙宜在沙发正前方
- 客厅宜摆放绿色植物（旺生气）
- 时钟宜摆在宅内吉位或命卦吉位

**忌：**
- 客厅忌设在住宅后半部
- 客厅忌阴暗狭窄
- 沙发背后忌有镜子
- 沙发背后忌空（无靠墙）
- 客厅财位忌无靠、凌乱、振动（如放音响）
- 电视背景墙忌在财位方
- 时钟忌挂在沙发上
- 客厅忌横梁压顶（尤其是沙发和座位上方）
- 客厅忌过多尖角物品
- 客厅忌满地镜子（造成空间混乱感）

### 客厅财位

**位置确定：**
- 进门后客厅对角线的角落（斜角）
- 固定财位：大门在右→财位在左对角；大门在左→财位在右对角

**财位宜：**
- 宜明亮（灯光充足）
- 宜平整干净
- 宜有靠（靠实墙）
- 宜摆放吉祥物（貔貅、金蟾、水晶、聚宝盆）
- 宜摆放绿色阔叶植物（发财树、金钱树、万年青）

**财位忌：**
- 忌无靠（背后是门窗）
- 忌凌乱（堆放杂物）
- 忌振动（放音响、电视）
- 忌有尖角冲射
- 忌放沉重物品（如大型柜子压住）
- 忌阴暗潮湿
- 忌放干花、假花

### 客厅沙发摆放

| 方式 | 宜忌 | 说明 |
|------|------|------|
| 靠实墙 | ✅宜 | 背后有靠，有安全感 |
| U形排列 | ✅宜 | 藏风聚气，利于交流 |
| L形排列 | ✅宜 | 适合小户型，聚气次之 |
| 背后是窗 | ❌忌 | 背后空虚，易漏财 |
| 背后是门 | ❌忌 | 人来人往，精神不安 |
| 背后是镜子 | ❌忌 | 反射造成不安 |
| 正对大门 | ⚠️视情况 | 若大门直冲沙发，需设屏风 |
| 横梁下方 | ❌忌 | 横梁压顶，精神压抑 |

### 客厅植物选择

| 植物 | 寓意 | 摆放位置 |
|------|------|----------|
| 发财树 | 招财进宝 | 财位或客厅显眼处 |
| 金钱树 | 金钱滚滚 | 财位 |
| 富贵竹 | 步步高升 | 东南方（财位方） |
| 万年青 | 健康长寿 | 客厅明亮处 |
| 龟背竹 | 健康长寿 | 客厅角落 |
| 兰花 | 高雅吉祥 | 客厅显眼处 |
| 仙人掌 | 化煞 | 窗台（有煞气处） |

### 客厅鱼缸

**宜：**
- 宜放在客厅财位（催财）
- 宜放在大门入口对角（明财位）
- 鱼缸形状宜圆形或长方形
- 养鱼数目宜单数（1、6、8、9为吉数）
- 宜养金鱼、锦鲤等吉祥鱼种

**忌：**
- 忌放在沙发背后（无靠山）
- 忌正对厨房（水火相冲）
- 忌放在神位下方
- 忌放在卧室
- 忌放死鱼（需及时清理）
- 忌形状尖锐（如三角形）

## 二、餐厅风水

### 餐厅的理想方位

| 方位 | 宜忌 | 说明 |
|------|------|------|
| **东南（巽）** | ✅大吉 | 巽属木，木生火（火为消化），最利餐厅 |
| **正东（震）** | ✅吉 | 东方生发之气，利于健康 |
| **正南（离）** | ✅吉 | 阳光充足，吃饭氛围好 |
| **正西（兑）** | ❌不宜 | 兑属金，金克木，不利消化 |
| **西北（乾）** | ❌不宜 | 乾属金，不宜做餐厅 |
| **西南（坤）** | ⚠️一般 | 需注意采光 |
| **正北（坎）** | ⚠️一般 | 较阴冷，需用暖色调补充 |
| **东北（艮）** | ⚠️一般 | 较阴冷 |

### 餐厅宜忌速查

**宜：**
- 餐厅宜设在东南方
- 餐厅宜与厨房相邻（方便上菜）
- 餐桌坐位宜朝向本命卦的吉方
- 餐厅宜用暖色调（增加食欲）
- 餐桌宜圆形或椭圆形（团圆和气）
- 餐厅宜挂温馨画作
- 餐厅灯光宜柔和、向下照射

**忌：**
- 餐厅忌设在西、西北方（金克木）
- 餐厅忌正对大门（气直冲，饮食不安）
- 餐厅忌正对厕所门（秽气影响食欲）
- 餐厅忌正对厨房门（油烟直冲）
- 餐桌忌摆放在与户主五行不合的方位
- 餐桌忌放在横梁下
- 餐桌忌正对镜子（反射造成不安）
- 餐桌忌过小或过大（与空间不协调）
- 餐厅忌用冷色调（蓝、黑）

### 餐桌形状选择

| 形状 | 吉凶 | 说明 |
|------|------|------|
| 圆形 | ✅大吉 | 象征团圆、和气，最推荐 |
| 椭圆形 | ✅吉 | 类似圆形，适合长形空间 |
| 正方形 | ✅吉 | 四平八稳，适合小家庭 |
| 长方形 | ⚠️一般 | 长边应靠墙，避免两边都坐人形成"舌战" |
| 三角形/异形 | ❌凶 | 尖角冲射，不利和气 |

### 餐厅酒柜

**宜：**
- 酒柜宜置角落
- 酒柜宜靠墙摆放
- 酒柜颜色宜与餐厅协调

**忌：**
- 酒柜忌摆在鱼缸旁（水气影响酒质）
- 酒柜忌摆在户主本命凶方
- 酒柜忌过高（不宜超过身高）
- 酒柜忌过于突出（影响动线）
