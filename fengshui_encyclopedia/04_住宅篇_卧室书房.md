## 一、卧室风水

### 主人房的理想方位

| 方位 | 宜忌 | 说明 |
|------|------|------|
| **西北（乾）** | ✅大吉 | 乾为天，代表男主人，最宜主卧 |
| **西南（坤）** | ✅吉 | 坤为地，代表女主人，宜夫妻主卧 |
| **正西（兑）** | ❌不宜 | 兑为少女，不宜做主卧 |
| **正北（坎）** | ⚠️一般 | 较阴冷，采光不足 |
| **正南（离）** | ✅吉 | 阳光充足，夫妻感情好 |
| **正东（震）** | ✅吉 | 生气方，利于健康和活力 |
| **东南（巽）** | ✅吉 | 利财运，夫妻和睦 |
| **东北（艮）** | ❌不宜 | 鬼门方，阴气重 |

### 卧室宜忌速查

**宜：**
- 卧室宜方正（不宜不规则形状）
- 卧室面积宜适中（10-20平米，不宜过大）
- 卧室宜在住宅后方（安静区域）
- 床头宜靠实墙（有靠山）
- 床宜三面有靠（床头靠墙，两侧有床头柜）
- 床头宜斜对门口（能看到门，但不正对）
- 卧室宜用暖色调（温馨舒适）
- 卧室灯光宜柔和（可调光）
- 卧室宜保持空气流通

**忌：**
- 卧室忌过大（超过20平米，气散不收）
- 卧室忌过小（压抑）
- 主人房忌设在西方
- 卧室忌正对大门（私密性差）
- 卧室忌正对厕所（秽气影响）
- 卧室忌正对厨房（火气冲）
- 床忌正对房门（门冲）
- 床头忌正对镜子（夜间易受惊吓）
- 床忌四周无靠（孤立）
- 床忌在横梁下（压顶）
- 床忌在窗户下（漏气，受风寒）
- 卧室忌有电视正对床（电磁辐射）
- 卧室忌有过多电器
- 卧室忌颜色过深或过艳
- 卧室忌摆放过多植物（夜间耗氧）

### 睡床摆放详解

**床头朝向：**

| 朝向 | 吉凶 | 说明 |
|------|------|------|
| 朝南 | ✅吉 | 顺应地磁，有利于睡眠质量 |
| 朝北 | ✅吉 | 地磁方向，有助于深度睡眠 |
| 朝东 | ⚠️一般 | 容易被阳光唤醒 |
| 朝西 | ❌不宜 | 日落西斜，影响休息 |
| 朝西南 | ⚠️一般 | 下午西晒 |
| 朝东北 | ⚠️一般 | 早晨寒冷 |

**床的方位细节：**

**宜：**
- 床头宜靠实墙，墙后最好是卧室以外空间
- 床头宜加床头板（增加靠山感）
- 床两侧宜留空间（各45-60cm）
- 床尾宜留空间（便于走动）
- 床底宜保持通风（不堆放杂物）

**忌：**
- 床头忌靠厕所墙（秽气渗透）
- 床头忌靠厨房墙（火气影响）
- 床头忌靠窗（漏气，受风）
- 床忌正对镜子（夜间反光易受惊）
- 床忌上方有横梁、吊扇、大吊灯
- 床忌对门（私密性差）
- 床忌在楼梯下
- 床底忌堆放杂物（影响气流）
- 床忌靠外墙（外墙温度变化大）

### 卧室颜色选择

| 方位 | 适宜色调 | 说明 |
|------|----------|------|
| 东/东南 | 浅绿、米白、原木色 | 木气生发，舒适自然 |
| 南 | 浅粉、浅紫、米色 | 火气适度，温馨浪漫 |
| 西南 | 黄色、米白、浅咖啡 | 土气厚重，稳定踏实 |
| 西/西北 | 白色、浅灰、米色 | 金气清爽，安静沉稳 |
| 北 | 浅蓝、米白、淡紫 | 水平衡，利于安眠 |
| 东北 | 浅黄、米色、浅咖啡 | 土气稳定 |

## 二、书房风水

书房是学习、工作的场所，风水主要影响学业和事业。

### 书房的理想方位

| 方位 | 吉凶 | 说明 |
|------|------|------|
| **东南（巽）** | ✅大吉 | 四绿文昌位，最利学业考试 |
| **正东（震）** | ✅吉 | 生气方，思维活跃 |
| **正北（坎）** | ✅吉 | 智慧之方，利于冷静思考 |
| **正南（离）** | ✅吉 | 阳光充足，利于阅读 |
| **西北（乾）** | ✅吉 | 利男主人事业决策 |
| **正西（兑）** | ⚠️一般 | 口舌方，不宜专注学习 |
| **西南（坤）** | ⚠️一般 | 易困倦 |
| **东北（艮）** | ✅吉 | 宜设书桌，旺文昌 |

### 书桌摆放

**宜：**
- 书桌宜以门口为向（能看到门但不在门正对线上）
- 书桌宜坐位有靠（背后有实墙）
- 书桌宜前方开阔（明堂宽）
- 书桌宜左方靠窗（左青龙采光好）
- 书桌宜面向吉方（按命卦）
- 书桌上方宜整洁（不放重物）

**忌：**
- 书桌忌被门冲（正对门）
- 书桌忌摆在中宫（房屋正中央）
- 书桌忌正对窗户（背后无靠且分心）
- 书桌忌背后无靠（背后是门或窗）
- 书桌忌横梁压顶
- 书桌忌背对门（不能看到来人）
- 书桌忌对墙太近（压抑）
- 书桌忌在厕所下方（楼上厕所）
- 书桌忌面向墙壁（眼界受限）

### 文昌位布置

**本命文昌位：**
- 甲乙日出生：文昌在巳（东南）
- 丙丁日出生：文昌在申（西南）
- 戊己日出生：文昌在酉（正西）
- 庚辛日出生：文昌在亥（西北）
- 壬癸日出生：文昌在寅（东北）

**文昌位布置宜：**
- 摆放毛笔、文昌塔
- 放置四枝富贵竹
- 书桌面向文昌方向
- 文昌位宜明亮

### 书柜摆放

**宜：**
- 书柜宜随书桌摆放
- 书柜宜靠墙（稳固）
- 书柜宜在书桌后方或侧方
- 书柜玻璃门宜透明（方便找书）

**忌：**
- 书柜忌有强光直射（书页变黄）
- 书柜忌过高（超过2米有压迫感）
- 书柜忌杂乱无章
- 书柜忌在书桌正前方（压迫）

## 三、儿童房风水

### 儿童房的理想方位

| 方位 | 适合年龄段 | 说明 |
|------|-----------|------|
| **正东（震）** | 男孩 | 震为长子，利于成长 |
| **东南（巽）** | 女孩 | 巽为长女，利于学习和才艺 |
| **正北（坎）** | ⚠️不推荐 | 过阴冷，影响健康 |
| **正南（离）** | ✅吉 | 阳光充足，利于活泼成长 |
| **正西（兑）** | ✅女孩 | 兑为少女，适合女孩房 |
| **东北（艮）** | ✅男孩 | 艮为少男，适合男孩房 |

### 儿童房宜忌

**宜：**
- 儿童房宜设在东方或东南方（生机勃勃）
- 儿童房宜色彩明亮活泼
- 儿童房宜有充足照明
- 儿童床宜靠墙摆放（安全）
- 儿童房宜设置学习区域
- 儿童房宜用环保材料

**忌：**
- 儿童房忌设在北方（阴冷）
- 儿童房忌颜色过深（压抑）
- 儿童房忌过多尖角家具
- 儿童床忌正对门
- 儿童床忌在横梁下
- 儿童房忌在厨房、厕所旁
- 儿童房忌设在地下室
- 儿童房忌放过多电器

### 儿童房颜色

| 性别 | 推荐颜色 | 说明 |
|------|----------|------|
| 男孩 | 浅蓝、浅绿、米白 | 活泼开朗，利于思维 |
| 女孩 | 粉色、浅紫、米白 | 温柔可爱，培养气质 |
| 通用 | 浅黄、浅绿、原木色 | 自然舒适 |

## 四、老人房风水

### 老人房的理想方位

| 方位 | 吉凶 | 说明 |
|------|------|------|
| **东南（巽）** | ✅吉 | 光线好，温暖舒适 |
| **正南（离）** | ✅吉 | 阳光充足，利于健康 |
| **正东（震）** | ✅吉 | 生气方，有活力 |
| **正北（坎）** | ❌不宜 | 阴冷，对老人关节不利 |
| **正西（兑）** | ⚠️一般 | 西晒，温差大 |

### 老人房宜忌

**宜：**
- 老人房宜设在一楼（免爬楼梯）
- 老人房宜靠近卫生间（方便起夜）
- 老人房宜朝南（采光好）
- 老人房的床宜朝南北方（顺应地磁）
- 老人房宜用暖色调
- 老人房地面宜防滑
- 老人房灯光宜柔和但明亮

**忌：**
- 老人房的床忌朝向东西方
- 老人房忌潮湿阴冷
- 老人房忌在楼梯旁（噪音）
- 老人房忌过于空旷（孤独感）
- 老人房忌深色过多（压抑）
- 老人房忌有门槛（绊倒风险）
