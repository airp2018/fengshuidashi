# 风水空间百科 · 主索引

> 搜索入口：按空间类型→方位→具体条目 三级检索
> 设计用于视觉模型匹配：拍照→识别场景→查索引→输出风水指导

---

## 使用方式

```
# 方式一：按场景查
场景:卧室 → 查 [卧室条目]
场景:办公室 → 查 [办公条目]

# 方式二：按场景+方位查
场景:卧室 + 方位:西北 → "主人房宜设在西北方，忌设在西方"
场景:厨房 + 方位:东方 → "厨房宜设在东、东南方"

# 方式三：按物品查
物品:床 → 查 [睡床摆放]
物品:办公桌 → 查 [办公桌摆放]

# 方式四：按问题查
问题:镜子对床 → "床头忌正对镜子"
问题:横梁压顶 → 改/避/化解方案
问题:门对门 → 化解方法
```

## 三、物品摆放在各空间的宜忌

### 客厅物品

| 物品 | 宜 | 忌 |
|------|----|-----|
| 沙发 | 靠实墙、U形排列 | 背后空/镜子、正对门 |
| 电视 | 在沙发正前方 | 在财位方 |
| 鱼缸 | 在财位、圆形 | 沙发后、厨房旁 |
| 时钟 | 在吉位/命卦吉位 | 挂在沙发上 |
| 植物 | 财位放阔叶植物 | 财位放带刺植物 |

### 卧室物品

| 物品 | 宜 | 忌 |
|------|----|-----|
| 床 | 床头靠实墙、三面有靠 | 正对门、在镜前、在梁下 |
| 衣柜 | 靠墙、不遮挡窗户 | 正对床 |
| 梳妆台 | 靠墙、不直对床 | 镜子对床 |
| 电视 | 不放在卧室 | 正对床（电磁） |

### 厨房物品

| 物品 | 宜 | 忌 |
|------|----|-----|
| 灶台 | 生气方、背后有靠 | 西方、对门、对窗 |
| 水槽 | 靠近窗户 | 紧邻冰箱 |
| 冰箱 | 厨房角落 | 正对灶台 |

### 书房物品

| 物品 | 宜 | 忌 |
|------|----|-----|
| 书桌 | 面门口、背靠墙、左靠窗 | 对门、对窗、背门 |
| 书柜 | 靠墙、在书桌后方 | 过高、在书桌前 |
| 电脑 | 左侧（青龙位） | 右手边 |

### 办公室物品

| 物品 | 宜 | 忌 |
|------|----|-----|
| 办公桌 | 背后有靠、前方开阔 | 正对门、背对门 |
| 电脑 | 桌左侧 | 正对门口 |
| 保险柜 | 财务室、背后有靠 | 直冲大门 |

## 四、常见问题速查

### 煞气类

| 问题/现象 | 风水名称 | 影响 | 化解 |
|-----------|----------|------|------|
| 大门直对后门/窗 | 穿堂煞/穿心煞 | 财来财去 | 设玄关/屏风/珠帘 |
| 两楼间缝隙对窗 | 天斩煞 | 健康受损 | 挂八卦凸镜 |
| 道路弯弓对宅 | 反弓煞 | 破财 | 放泰山石敢当 |
| 墙角直冲门窗 | 尖角煞 | 意外伤灾 | 放绿植/挂镜子 |
| 长路直冲门窗 | 枪煞 | 健康事业损 | 设屏风/挂五帝钱 |
| 大门对楼梯（下） | 泄气煞 | 财气下泄 | 门槛加高/挂镜 |
| 大门对楼梯（上） | 冲煞 | 好运被冲 | 放植物挡 |
| 独楼高耸无靠 | 孤峰煞 | 孤立无助 | 靠背位放高柜 |
| 横梁压顶 | 横梁煞 | 精神压抑 | 吊顶包梁/移位置 |
| 大门对电梯 | 开口煞 | 财气被吸 | 设玄关/挂五帝钱 |
| 镜子对床 | 镜光煞 | 睡眠不安 | 移镜子或加帘 |
| 床头对窗 | 漏气 | 健康受损 | 移动床位 |
| 大门对厕所 | 秽气冲 | 健康财运差 | 常关门/设屏风 |

### 布局问题类

| 问题 | 影响 | 化解/调整 |
|------|------|-----------|
| 卫浴在房屋中心 | 最凶格局 | 尽量改造 |
| 厨房在西北 | 火烧天门，伤男主人 | 减少明火，多用白色 |
| 卧室过大 | 气散不聚 | 分区或减小空间感 |
| 户型缺角 | 对应家庭成员受损 | 用吉祥物补角 |
| 前宽后窄 | 散财格局 | 后院加高墙/植物 |
| 门对门（两家） | 口舌是非 | 挂中国结/五帝钱 |

## 八、视觉匹配 JSON → 百科映射

```
# 视觉模型输出格式
{
  "scene_type": "卧室",              → 04_住宅篇_卧室书房.md
  "orientation": {
    "door_position": "西北",         → 西北角：乾位，查卧室方位节
    "window_position": "东"         → 东窗吉
  },
  "elements": [
    {"item": "床", "position": "中", "direction": "南北"}  → 查"睡床摆放"
    {"item": "镜子", "position": "床对面"}                   → 查"镜子对床"问题
  ],
  "concerns": ["镜子对床"]          → 查"常见问题速查"→镜光煞
}

# 匹配后输出
{
  "guides": [
    {"level": "吉", "rule": "卧室床宜朝南北方，顺应地磁"},
    {"level": "凶", "rule": "镜子忌正对床，夜间反光易受惊"},
    {"level": "建议", "action": "建议将镜子移开或加镜帘"}
  ]
}
```
