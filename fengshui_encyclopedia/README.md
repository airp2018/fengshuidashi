## 视觉匹配方案

### 流程

```
[拍照] → [多模态视觉模型] → 结构化描述 → [百科检索] → 风水指导
```

### 视觉模型输出格式（建议）

视觉模型分析一张空间照片后，输出以下结构化 JSON：

```json
{
  "scene_type": "卧室|客厅|厨房|办公室|商铺|浴室...",
  "orientation": {
    "camera_facing": "东|南|西|北|东南|西南|东北|西北",
    "door_position": "描述",
    "window_position": "描述"
  },
  "elements": [
    {"item": "床", "position": "房间中央偏西", "relation": "床头靠西墙"},
    {"item": "书桌", "position": "东南角", "relation": "面朝门口"},
    {"item": "镜子", "position": "对面是床", "relation": ""}
  ],
  "colors": ["白色", "米黄", "原木色"],
  "concerns": ["横梁压顶", "门对门", "镜子对床"]
}
```

### 匹配逻辑

百科文件的搜索入口设计为多维度：

1. **场景维度**：卧室→查04_卧室篇 → 儿童房/主卧/老人房子类
2. **方位维度**：东/南/西/北/东南/西南/东北/西北 → 查各章节方位节
3. **元素维度**：床/书桌/镜子/灶台 → 查物品摆放子节
4. **问题维度**：横梁压顶/门对门 → 查禁忌与化解节

### 快速搜索语法

```bash
场景:卧室 + 方位:西北 → "主人房宜设在西北方，忌设在西方"
场景:厨房 + 方位:东方 → "厨房宜设在东、东南方"
场景:办公室 + 物品:办公桌 → "办公桌宜背后有靠，忌正对大门"
场景:商铺 + 问题:天桥 → "商铺忌向着天桥"
```
