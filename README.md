# ☯ 风水大师 FengShuiMaster

> **拍下你所在的空间，看看家具和方位应该怎样调整。**

[立即在线体验](https://fengshuidashi.onrender.com/) · 手机浏览器可直接拍照使用

FengShuiMaster 是一个面向手机使用的空间风水分析工具。拍下卧室、客厅、办公室或商铺，AI 会识别门窗、家具和主要物品的空间关系，再结合罗盘方位与专门整理的风水百科，给出具体的室内布局和摆放调整建议。

## 它有什么不同？

### 📱 拿起手机，拍照就能看

不需要绘制户型图，也不需要先学习八卦、五行等术语。打开网页，拍下现场或从相册选择照片，即可开始分析。

### 👁️ 先看现场，再谈风水

AI 会先观察照片中的门窗、床、沙发、书桌、镜子、炉灶、收银台等元素，以及它们之间的空间关系。分析围绕真实场景展开，而不是只回答泛泛的风水问题。

### 📚 有一套专门的风水百科

项目内置了按“场景、方位、物品”整理的风水百科数据库，覆盖方位与五行、大门与玄关、客厅与餐厅、卧室与书房、厨房与卫浴、办公室、商铺等主题。视觉识别结果会与对应百科条目匹配，为解释提供更具体的参考。

### 🧭 把空间方位考虑进去

手机支持时可以读取方向传感器；不支持时也可以手动拖动罗盘校准。照片中的布局关系与实际朝向结合后，建议会更贴近现场。

### 🪑 建议落到具体摆放

结果不仅说明“宜”与“忌”，还会尽量指出：

- 哪个位置值得注意；
- 门、窗与主要家具之间有什么关系；
- 床、沙发、书桌、镜子、炉灶等物品可以怎样调整；
- 哪些问题可以通过改变朝向、距离、遮挡、颜色或收纳方式改善。

## 怎么使用？

1. 用手机打开[在线网站](https://fengshuidashi.onrender.com/)。
2. 拍摄当前空间，或从相册选择一张照片。
3. 确认场景类型，并按实际情况校准罗盘方向。
4. 回答 AI 根据照片生成的补充问题，也可以跳过直接分析。
5. 查看空间风水报告，并复制建议留存或分享。

为了让识别更准确，照片最好能同时拍到门窗、主要家具和空间整体关系，避免画面过暗、严重倾斜或只拍摄局部物品。

## 支持哪些场景？

| 场景 | 重点关注 |
| --- | --- |
| 🛏️ 卧室 | 床头、镜子、门窗、衣柜、色彩与睡眠空间 |
| 🛋️ 客厅 | 沙发、电视墙、动线、采光、财位与装饰摆放 |
| 🍳 厨房 | 炉灶、水槽、冰箱、门口及水火关系 |
| 📚 书房 | 书桌朝向、座位靠山、门窗与文昌位参考 |
| 💼 办公室 | 办公桌、座位、入口、采光与工作动线 |
| 🏪 商铺 | 门面、收银台、客流动线、陈列与内部布局 |
| 🍽️ 餐厅 | 餐桌形状与位置、厨房关系、灯光与动线 |
| 🚿 卫浴 | 门口、马桶、干湿关系、通风与相邻空间 |

## 风水百科包含什么？

百科以空间使用为入口，并按方位和物品继续检索，主要包括：

- 八个方位、八卦、五行与常见空间关系；
- 大门、玄关、门对门、鞋柜与屏风；
- 客厅、餐厅、沙发、电视墙、鱼缸与财位；
- 主卧、儿童房、老人房、床、镜子、衣柜与书桌；
- 厨房、炉灶、水槽、冰箱、卫浴、阳台与庭院；
- 办公桌、经理室、会议室、商铺门面、收银台与陈列；
- 常见布局问题、颜色参考和可执行的调整方式。

## 开源运行

项目使用 Node.js、Express、视觉模型 API 与本地风水百科构建，可通过 Docker 部署。配置好所需环境变量后运行：

```bash
npm install
npm start
```

当前在线版本由 Render 自动部署，GitHub `main` 分支更新后会同步发布。
