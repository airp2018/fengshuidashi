# FengShuiMaster README 产品说明设计

## 目标

README 面向普通用户介绍产品，不写成部署档案或开发手册。用户应在第一页迅速理解：这是一个可以用手机拍摄真实空间、结合 AI 视觉识别、罗盘方位和专门风水百科，给出室内布局与物品摆放建议的工具。

## 核心亮点

1. 手机拍照即用，不要求用户理解户型图或风水术语。
2. 先识别门窗、家具和物品之间的真实空间关系，再生成分析。
3. 使用按场景、方位和物品整理的专门风水百科，不只是通用 AI 对话。
4. 支持手机方向传感器与手动罗盘校准，把空间朝向纳入参考。
5. 建议落到床、沙发、书桌、镜子、炉灶、收银台等具体物品的摆放调整。

## README 结构

1. 一句话产品定位与在线体验入口。
2. 五项核心差异化亮点。
3. 手机端五步使用流程与拍摄建议。
4. 八类支持场景及各自关注重点。
5. 风水百科覆盖范围。
6. 极简开源运行说明。
7. 传统文化参考与专业安全声明。

## 文案边界

- 不添加尚未实现的功能。
- 不展示密钥、密码、兑换码或用户数据。
- 不宣称科学鉴定、预测命运或保证现实效果。
- 技术和部署内容只作简短补充，不抢占产品亮点。

## 验收标准

- README 中文显示正常，首屏能看懂产品用途和差异。
- 手机拍照、视觉识别、罗盘、百科匹配、具体摆放建议成为叙事主线。
- 所有场景和功能描述都能在现有产品或百科文件中找到依据。
- 在线体验链接有效，Markdown 不包含敏感信息。
