# FengShuiMaster README 重写设计

## 目标

重写项目根目录 README，使普通用户能快速理解产品用途和使用流程，同时让开发者能够完成本地运行、环境配置与 Render 部署。内容以中文为主，准确描述现有功能，不增加尚未实现的能力。

## 读者与叙事顺序

README 兼顾两类读者，并采用产品优先的阅读顺序：

1. 普通用户先看到项目定位、在线体验、手机拍照流程、支持场景、百科覆盖范围和结果说明。
2. 开发者随后看到技术架构、数据流、本地运行、环境变量、Docker/Render 部署和目录结构。

## 内容结构

1. 项目标题、简短定位与在线体验入口。
2. 核心体验：拍摄或选择空间照片、确认场景、补充问题、结合罗盘方位和百科生成建议。
3. 支持场景：卧室、客厅、厨房、书房、办公室、商铺、餐厅、卫浴。
4. 风水百科：方位与五行、大门玄关、客厅餐厅、卧室书房、厨房卫浴、办公室、商业空间及补充条目。
5. 报告内容：空间观察、布局宜忌、家具与物品摆放、可执行调整建议。
6. 手机使用方法与拍摄建议。
7. 技术架构与数据流：前端页面、Express 服务、视觉模型、本地百科检索、飞书同步。
8. 本地运行、必要环境变量、Docker 与 Render 部署。
9. 项目目录、安全注意事项和传统文化参考声明。

## 文案边界

- 使用“传统文化视角下的空间布局参考”等准确表述，不宣称科学鉴定、预测命运或保证效果。
- 不在 README 中展示任何密钥、兑换码、后台密码或真实用户数据。
- 不声称支持代码中不存在的登录、云端图片存储、自动装修设计或专业测绘能力。
- 明确照片应尽量覆盖门窗、主要家具和空间整体关系；方位信息可由手机传感器或手动罗盘辅助。

## GitHub 仓库信息

同步更新仓库顶部简介，概括“手机拍摄空间场景、AI 视觉分析、本地风水百科匹配与室内摆放建议”，保留现有在线网站地址。

## 验收标准

- README 中文显示正常，不再出现乱码。
- 在线体验、功能、场景、百科、技术、运行和部署信息齐全。
- 所有功能描述均能在现有页面、服务端接口或百科文件中找到依据。
- Markdown 结构清晰，链接可用，不含敏感信息。
